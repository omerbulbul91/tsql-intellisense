## Add Your First Connection

T-SQL IntelliSense connects directly to your SQL Server instances to provide real-time schema information.

### Quick Start

1. Click the **T-SQL IntelliSense** icon in the Activity Bar (left sidebar)
2. Click the **+** button to add a new connection
3. Fill in your server details:
   - **Server**: `localhost` or `server\instance`
   - **Database**: Your database name
   - **Authentication**: Windows or SQL Login

### Connection Profiles

You can save multiple connection profiles and switch between them. Each profile stores:
- Server address and port
- Database name
- Authentication credentials
- Optional: SQL Project path for DDL sync

> **Tip**: Use `Ctrl+Shift+P` → **T-SQL: Connect to Database** to quickly connect.
